Entry for the make.fun bounty [Make the best spot the difference game](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451) — Lantern Lane, a complete spot-the-difference game: two near-identical night-market scenes side by side, 3 rounds, 28 differences to find, with hints, a countdown and a score. It plays offline in a desktop browser, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
